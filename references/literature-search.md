# 文献检索规则

## 触发条件

当当前方案难以判断、用户要求查找相近论文，或需要验证已有方法的理论和经验依据时进行检索。检索前明确问题、领域、时间范围、任务、数据集和评价指标。

## 优先顺序

1. 当前日期往前两年的工作；
2. CCF-A 会议；
3. 公认的高水平 CCF-B 会议；
4. 与当前数据、模型、指标和资源条件相近的工作。

优先级是筛选顺序，不意味着较旧或较低等级的工作自动无效。

## 比较要求

记录论文的任务、数据、预处理、模型规模、额外数据、评价指标、资源条件和实验协议。区分论文中的正式结论、作者假设、经验观察和待验证的启发式想法。

借鉴论文时说明哪些思想被采用、为什么适合当前项目、哪些条件无法迁移、需要哪些消融。只有比较协议公平时才讨论 SOTA 或超过基线。

论文信息应尽量由原论文、正式会议页面或可靠索引核验。找不到足够可靠的证据时，直接说明证据不足，不用二手总结替代原始依据。
